# Practice cases and acceptance checks

All inputs below are fictional. Their quantities, excerpts, and source cards are exercise material. To try a case, give the agent the linked file and ask it to use the skill. For an independent trial, provide only the case and skill folder and compare the result with this page afterwards.

| Case | Observable result |
| --- | --- |
| [Materials paper outline](framing.md) | Maps all four paragraphs, explains why the placement of the test conditions matters, and proposes a sequence connecting design, result, and inference. Separates short-term controlled performance from field or long-term claims. Leaves the manuscript at the requested planning stage. |
| [Energy literature synthesis](synthesis.md) | Builds a comparison across conditions and designs, treats the A and D results as dependent, distinguishes a combined simulated retrofit from a measured controls-only result, and identifies what needs full-text verification. Keeps the direction and uncertainty of B intact. |
| [Monitoring model review](manuscript-review.md) | Identifies the station as the grouping unit for new-station transfer and the full-record calculation as a documented route for information from test records to enter preprocessing. Puts the observed RMSE in context, flags missing calibration evidence and the inaccurate caption, and distinguishes proposed validation from work already done. |
| [Response to fatigue reviewers](point-by-point-response.md) | Addresses all three comments using actual section or figure anchors and handles both components of the third comment. Identifies panel B as the chosen partial remedy and explains the retained figure. Accounts for the requested uncertainty interval as outstanding. Accurately reports the scope of the tests and the limitation added to the Discussion. |
| [Chinese local copyedit](local-copyedit.md) | Returns a readable single paragraph for the requested passage. Preserves the sample count, comparator, 2.3 °C estimate, interval, dates and weather conditions, and direction of comparison with the cited example. |
