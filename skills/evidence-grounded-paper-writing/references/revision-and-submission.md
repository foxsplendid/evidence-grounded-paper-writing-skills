# Revision and submission

## Link comments to actual revisions

1. Identify the submitted baseline, current working draft, and version that will accompany the response. Preserve each reviewer comment's meaning and identifier. If one comment raises several issues, account for each material part.
2. Match each issue to an action. Accept a correction, partially adopt a suggestion, clarify the text, or explain the reason for a different decision. A reviewer suggestion can be addressed without the specific wording or method they proposed when the underlying issue is resolved. Ground any disagreement in the evidence and use a constructive tone.
3. Apply the authorized changes or work from a verified revised version. For changes that affect a claim, check the abstract, results, discussion, tables, and captions that also carry it. Distinguish a manuscript change from an explanation supplied only in the letter.
4. Draft the response using the requested format. For each point, say what changed or explain the reason for the decision, cite the current location, and quote changed text only when useful or requested. Verify quotations, page and line numbers, and pointers against the returned version. When pagination is pending, use stable section, table, figure, or paragraph anchors.

For a large set of comments, track the original point, decision, verified change, location, and any pending dependency. Mark proposed analyses or edits as pending in working notes. A final reply should claim only completed work or explicitly explain an open item.

## Check the requested delivery files

Use current official instructions for the target outlet when the user requests a submission check. Confirm the article type, referencing and caption style, file requirements, and relevant statements such as availability, AI-use disclosure, or declarations where applicable. Where instructions are ambiguous, compare current examples and surface the ambiguity. Use only author information and metadata provided or authorized.

When Word tracked and clean versions are requested, verify that the tracked file corresponds to the designated baseline and that accepting revisions yields the intended clean text. Check document structure, caption numbering, cross-references, and layout in the available format. Confirm that comments, fields, revision markers, and metadata match the requested deliverable. For other formats verify the applicable rendering or diff.

Before delivery, compare the active manuscript, figure files and captions, bibliography, and letter anywhere a change affects more than one of them. Verify archive contents when packaging is requested. Report any check that depends on missing source files, journal instructions, or an unavailable viewer.
